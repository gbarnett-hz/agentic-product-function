# RR-<NNN>: <Title>

Format: agile spike (question, exit criteria, deliverable) combined with a research brief (objective, context, scope, method, follow-ups). The time-box of a classic spike is replaced by a depth level.

| | |
|---|---|
| Status | Draft / Ready |
| Requester | <name> |
| Date | <YYYY-MM-DD> |
| Related | <PRD-NNN / SPEC-NNN / RR-NNN, or none> |
| Type | Investigation / Technology evaluation / Proof of concept / Feasibility / Landscape survey |
| Depth | quick / standard / deep |

Depth: **quick** = a few angles, answer from the best available evidence. **standard** = several angles, adversarial pass, cross-checked citations. **deep** = exhaustive angles, adversarial and independent replication of key claims, primary sources preferred.
